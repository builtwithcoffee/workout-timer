Quick start & how it works

Workout Timer Guide

A focused, local-first timer for preparing, running, and logging workouts on an iPhone or iPad.

Quick start

  1. Choose a workout

    Select a built-in plan, load a saved workout file, or create a basic or structured workout.

  2. Check today’s prescription

    Before training, confirm that the exercises, sets, targets, rests, and block order match the workout you intend to perform.

  3. Start and follow the timer

    Tap Set done after manual exercises. Timed exercises and rests advance automatically, and structured workouts pause before each new block.

  4. Log what actually happened

    After finishing, choose Log workout. Review the reps and weights, add optional private notes, and save the session to History.

  5. Use or back up the result

    Copy the concise workout overview for an activity description. Export History separately when you want a complete backup.

About the included workouts

BuiltSimple – Men of Momentum uses five progressive program tracks. An Entry Test determines where someone starts, and their assigned track may change as they progress.

  1. 01Foundation
  2. 02Momentum
  3. 03Forge
  4. 04Rise
  5. 05Built

The included library currently contains Lower Body, Pull, and Dip workouts for Momentum · Level 02, plus Rise Lower Body, Dip, Pull, and Push workouts. The identical optional-cardio workout is listed once in the separate Optional section. Other tracks and weeks may differ.

Workout Timer does not connect to BuiltSimple, select a track, or update its programming automatically. Always treat your current BuiltSimple assignment as the authoritative workout.

Prepare your current week

  1. Open the assigned workout

    Check your current track and week in BuiltSimple before changing anything in Workout Timer.

  2. Choose the closest starting point

    Select the matching track and workout when it is included. Otherwise, choose the closest plan, create a new workout, or load a plan you prepared earlier.

  3. Edit it to match

    Use Edit workout to change blocks, exercises, sets, targets, rests, timers, or added weight for an individual set. Leave added weight blank for bodyweight sets. Use a basic workout for straightforward sets and a structured workout for sections, timed work, for-time blocks, or AMRAPs.

  4. Name and save the plan

    Give it a clear name that identifies the track, week, and focus when useful. Choose Save to keep a portable .workout.json file in Files.

  5. Load it when needed

    Choose Load to bring a saved workout file back. Review it against the current assignment before starting.

Save before switching: Workout Timer keeps one editable current workout. Selecting another built-in plan replaces that working plan, and selecting a built-in again loads its original version.

While you train

Manual sets

Tap Set done. When a linked rest follows, you can quickly adjust the completed reps and weight.

Structured blocks

Review the next block, then tap Start block. A skipped block is left out of the saved session.

AMRAPs

Let the timer finish or end it early. Record completed rounds and extra reps during the final review.

Your plans and data

Workout Timer is local-first. It has no account, server, subscription, or analytics. Plans, settings, and workout history stay in the browser on this device and are not uploaded by the app.

After the first online launch, the installed app works without gym Wi-Fi or cellular service. A connection is only needed to load the site initially and check for app updates.

Workout file

Save and Load handle a reusable plan. The file does not include completed-session history.

History backup

Export history and Import history handle completed sessions. They do not replace the current workout plan.

Copied overview

A concise plain-text summary for sharing elsewhere. It is convenient, but it is not a complete history backup.

Keep a backup: Export History before clearing browser data, replacing a device, or moving your records to another iPhone or iPad.
