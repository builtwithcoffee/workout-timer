# iPhone import flow reference — app 1.0.79

These screenshots record the Workout Timer side of the iPhone pack-import flow as it appeared in app version **1.0.79** on September 4, 2026.

They are implementation references, not member-facing guide images. The app interface may change, so do not add these screenshots to the public guide without confirming that they still match the current release.

The recorded flow is:

1. Open the **Workout** tab and choose **Manage packs**.
2. Choose **Import workout pack**.
3. Select the saved `.workout-pack.json` file in the iPhone Files picker.

Files:

- `01-track-selection.png` — track chooser and Manage packs entry point.
- `02-manage-packs.png` — Manage packs and Import workout pack action.
- `03-files-picker.png` — iPhone Files picker with a saved Forge pack in Recents.

The two FITR screenshots used in the public guide live in `assets/guide/`. They document the more stable attachment-preview and Save to Files handoff outside Workout Timer.
